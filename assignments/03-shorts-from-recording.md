# Assignment 3, Shorts From a Recording

Drop one recording into `input/recordings/`, then tell the agent to run assignment 3.

## A good source recording

- It is 30 to 45 minutes long.
- It has one main speaker.
- The voice is clear.
- It contains no client or customer talk.
- It does not name an insurance carrier or contracted company.
