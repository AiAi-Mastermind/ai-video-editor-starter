# Assignments

Assignments are ready-made briefs. The agent reads one, asks only what it needs, and puts finished work in `output/drafts/`.

Paste one of these prompts:

```
Run assignment 0.
```

```
Run assignment 1 with the sample brief.
```

```
Run the weekly batch from assignments/weekly-brief.md.
```

You can replace the sample fields with your own words at any time. Never put customer details in a brief.
