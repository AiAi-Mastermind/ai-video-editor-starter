# Output

- `drafts/` holds everything the agent makes. A person must review it.
- `approved/` holds copies a person approved by typing "approved" in the same session.
- `posted/` may record files a person posted themselves.

The agent never publishes, posts, uploads, sends, or moves work to `posted/`.

The agent may COPY a draft to `output/approved/` only after the member types the word approved in that session. The draft stays in `output/drafts/`. A person posts it.
